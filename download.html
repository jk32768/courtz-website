Before You Install

CourtZ is currently distributed as an Android APK.

Android may ask you to allow installation from this source. This is normal when installing applications that are not downloaded from Google Play.

CourtZ requires Android 9 or later.

Installation

  1. Download the CourtZ APK.
  2. Open the downloaded file.
  3. If prompted, allow installation from this source.
  4. Complete the installation.
  5. Launch CourtZ.
  6. Enter your club name and email address to begin your free 30-day trial.

Getting Started

After installing CourtZ:

  1. Create your player list.
  2. Create a Session Profile.
  3. Select today's attendance.
  4. Generate your first games.

Everything else is explained in the online User Guide.

Trial Licence

If you later purchase a licence, simply enter your licence key from Options → About. Your players, Session Profiles and application settings are preserved.

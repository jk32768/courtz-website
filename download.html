Installing on Android

CourtZ is distributed directly from the CourtZ website as a standard Android application (APK).

1
Tap Download for Android.
2
Open the downloaded CourtZ-3.0.apk file.
3
Tap Install. If Android asks for permission to install apps from this source, allow it and then continue with the installation.
4
Tap Open to start CourtZ.

Installing on Windows

Installing CourtZ on Windows only takes a minute or two.

1
Download CourtZ-3.0-Setup.exe.
2
Open the downloaded installer.
3
Because CourtZ is not distributed through the Microsoft Store, Windows may display a SmartScreen warning the first time you run the installer. Click More info and then Run anyway to continue.
4
Follow the installation wizard and launch CourtZ.

On first launch, enter your club name and email address to begin your free 30-day trial.

Because CourtZ is downloaded directly from the CourtZ website rather than Google Play, Android may ask you to confirm that you wish to install it. Simply follow the on-screen instructions and then continue with the installation.

Need more help? Read the Android Installation Guide.

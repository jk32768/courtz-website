Installing the Android Test Version

The public release installs through Google Play. For the direct-download test version, follow these APK installation steps.

1
Tap Download Android Test Version.
2
Open the downloaded CourtZ-Android.apk file.
3
Tap Install. If Android asks for permission to install apps from this source, allow it and then continue with the installation.
4
Tap Open to start CourtZ.

Installing the Windows Test Version

Use the Windows test-version download above, then follow these steps.

1
Download CourtZ-Windows-Setup.exe.
2
Open the downloaded CourtZ-Windows-Setup.exe file. If your browser warns that the file isn't commonly downloaded or asks you to confirm that you wish to keep it, choose Keep (or the equivalent option) to continue.
3
Windows may display a SmartScreen warning because CourtZ is downloaded directly from the CourtZ website rather than the Microsoft Store. If this happens, select More info and then Run anyway.
4
Follow the installation wizard and launch CourtZ.

These warnings are normal for new applications downloaded directly from a developer's website rather than through the Microsoft Store. As CourtZ becomes more widely downloaded, your browser may stop displaying the download warning.

On first launch, enter your club name and email address to begin your free 30-day trial.

When installing the Android test APK directly from this website rather than Google Play, Android may ask you to confirm that you wish to install it. Simply follow the on-screen instructions and then continue with the installation.

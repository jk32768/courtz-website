## Version 3.3.1

Version Code 11

- Added a tick icon to indicate that a player is attending.
- Changed Expected Games adjustment from a long press to tapping the player's status icon.

## Version 3.3.0

Version Code 10

- Added Expected Games, allowing players to specify how many games they expect to play.
- Players with an Expected Games target are given additional priority during round generation to help them reach their target.
- Added the option to remove players before generating the next round after they reach their Expected Games target.

---

## Version 3.2.0

Version Code 9

- Added Configuration Export for desktop devices.
- Added configuration sharing for mobile devices.
- Added the ability to export or share a complete configuration or selected Session Profiles.
- Added Replace, Merge and Selected Profiles options when importing configurations.
- Required players are automatically included when exporting or sharing selected Session Profiles.
- Imported player details and Session Profile settings are updated during merges.
- Improved cross-platform file sharing using standard JSON files.
- Added validation for invalid or non-CourtZ configuration files.
- Improved refresh behaviour after importing data.

---

## Version 3.1.0

Version Code 8

- Improved player rotation in smaller sessions by increasing the minimum number of rounds before players are partnered together again.

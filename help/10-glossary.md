\## Session



A series of games played by a group of players. During a session, CourtZ generates successive rounds of games using the current session settings.



\---



\## Session Profile



A template that stores the regular players and default game settings for a session.



Session Profiles make it easy to recreate regular sessions.



\---



\## Session Settings



The settings currently used to generate games during a session.



A session normally starts with the settings defined by the selected Session Profile. These can be temporarily changed using \*\*Settings\*\*, available from the \*\*Options\*\* (⋮) menu, without modifying the Session Profile.



\---



\## Skill Level



A value between \*\*0\*\* and \*\*10\*\* that represents a player's playing ability.



CourtZ uses Skill Levels when generating games.



Skill Levels are colour coded throughout the application:



\- \*\*Green\*\* represents lower Skill Levels.

\- \*\*Blue\*\* represents average Skill Levels.

\- \*\*Red\*\* represents higher Skill Levels.



Intermediate Skill Levels are shown using shades between these colours.



\---



\## Waiting Room



The list of players who are not currently on court.



CourtZ automatically moves players between the Waiting Room and the courts as new rounds are generated.

# Glossary

## Session

A session is a series of games played by a group of players.

During a session, CourtZ generates successive rounds of games using the current session settings until the session finishes.

---

## Session Profile

A Session Profile is a template that stores the regular players and default game settings for a session.

Session Profiles make it easy to recreate regular club sessions without selecting the same players and settings each time.

---

## Session Settings

Session Settings are the options currently used when generating games during a session.

A session normally starts with the settings stored in the selected Session Profile. These can be temporarily changed using **Session Settings** from the **Options** menu without modifying the original Session Profile.

---

## Skill Level

A Skill Level is a value between **0** and **10** that represents a player's playing ability.

CourtZ uses Skill Levels when generating balanced and competitive games.

Skill Levels are colour coded throughout the application:

- **Green** – beginner
- **Blue** – intermediate
- **Red** – advanced

Intermediate Skill Levels are displayed using shades between these colours.

---

## Team Skills

A Session Setting that controls how CourtZ balances player abilities when generating games.

- **Balanced** attempts to create evenly matched teams by keeping the total Skill Levels of each side as close as possible.
- **Competitive** attempts to group players of similar Skill Levels together.

---

## Waiting Room

The Waiting Room contains players who are not currently playing.

Players enter the Waiting Room when:

- there are more players than available court spaces
- they are waiting for their next game
- they join a session after play has started
- they are resting between rounds

CourtZ automatically moves players between the Waiting Room and the courts as new rounds are generated.

---

## Games Display

Games Display is a simplified, player-facing view of the current court allocations.

It is designed to be displayed on a tablet, television or projector so players can easily see where they are playing.

---

## New Game

The **New Game** (refresh) button generates the next round of games using the current Session Settings, player availability and Waiting Room.

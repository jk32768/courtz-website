\# Display Games



Display the current court allocations in a clear, easy-to-read format.



The Display Games page is designed for players. It presents the current court allocations using larger court displays than the standard Games page, making them easier to read during a session.



\---



\## Viewing the Games



Select \*\*Display Games\*\* from the Games page.



The Display Games page shows the current court allocations, including the players on each court.



Whenever a new round of games is generated, the display updates automatically.



\---



\## Using Display Games



Display Games is intended to be visible to players throughout the session.



The larger court displays are easier to read from a distance and work well on larger tablets. If required, your device's screen can also be cast to a television or projector for improved visibility.



\---



\## Player Skill Badges



Player skill badges are intentionally hidden on the Display Games page.



Player skill levels are still used by CourtZ when generating balanced games, but they are not shown on the player display.
